# Sauti Adapt ML benchmark harness

Status: **NOT VERIFIED** for new public proxy measurements.
This folder contains benchmark calculations only. It does not download
recordings or run any pretrained model without a separately authorised run.

## Current evidence boundaries

The participant-specific LoRA experiments in Colab are private research.
They are not the public Google Speech Commands benchmark. Do not copy
private recordings, transcripts, weights, identifiers or credentials into Git
or publish the prediction-level output.

Google Speech Commands is a **typical speech** corpus. Its dataset adapter,
licence verification and explicitly approved access must precede any use.
Even a measured result on it cannot establish performance for someone with
atypical speech, motor impairment or cerebral palsy.

## Statistics

`ml.bench.metrics` provides:

* Seeded bootstrap percentile intervals for repeated speaker/seed trials
* Clopper-Pearson one-sided 95 per cent upper limit for unknown false accepts
* Observed false accepts with the sample count, never a false claim of zero risk
* p50 and p95 latency over recorded processing times

No result is generated by importing the module. The calling experiment
must supply actual trial measurements and provenance.

## Release policy

See `services/speech-api/sauti_ml/release_gate.py`. The default evidence
gate demands at least 30 unknown audio clips across calibration and test,
no false command activations, and a 95 per cent upper bound no greater
than 10 per cent. This is a minimum pilot gate, not proof of real-world safety.
Weak-evidence status never authorises any Controller action.

## Not yet verified

* Repeated speaker-disjoint trials on Google Speech Commands
* Dataset licensing and approved acquisition
* Native-speaker Kiswahili command negative pool
* Real participant command false-accept rate
* Model encoder layer/pooling selection
* CPU process memory and p50/p95 inference latency
* Optional weight-space-programming experiment
